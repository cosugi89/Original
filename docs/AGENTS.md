# プロジェクト内エージェント指示

このファイルは、このリポジトリで作業する AI エージェント向けのプロジェクト内ルールです。
詳細な決めごとは `.codex/` 以下の各ファイルを参照してください。

## 参照する方針

- コーディング方針: `.codex/agent-coding-policy.md`
- Unity 参照方針: `.codex/unity-reference-policy.md`
- Appearance 現状メモ: `.codex/appearance-current-spec.md`
- MasterData 方針: `.codex/masterdata-current-direction.md`
- 仕様書 / TODO 更新方針: `.codex/document-update-policy.md`

## Hub としての役割

- `AGENTS.md` はプロジェクト内ルールの入口として扱う。
- 仕様、TODO、作業メモの更新判断は、まず本ファイルを確認し、詳細は `.codex/document-update-policy.md` を参照する。
- 下位フォルダに個別ルールがある場合は、その範囲の作業に限って追加で尊重する。

## 必須運用

- 実装、設計、UI 配線、データ構造、セーブ仕様に変更が入る作業では、完了前に仕様書と TODO の更新要否を必ず確認する。
- 仕様と実装が衝突した場合は、原則として現行実装を正として仕様書を更新する。
- プロジェクト全体 TODO には未完了タスクだけを残し、完了済み、重複、短命な分解メモを残し続けない。
- 一時メモや短期 TODO を作った場合は、消化後に削除するか、必要部分だけを恒久ドキュメントへ反映する。
- ユーザーとの会話で仕様や方針が確定した場合は、コード変更の有無にかかわらず、関連ドキュメントへの反映を検討する。
- `docs/` 配下の仕様書、TODO、作業メモだけでなく、`.codex/` 配下のエージェント向け方針や作業メモも日本語で記述する。コード識別子、API 名、ファイルパス、Unity メニュー名などは必要に応じて英語のまま残してよい。

## 優先順位

- このリポジトリ内の作業では、上記ファイルの方針を尊重する。
- ユーザーの発話が質問である場合は、まず質問への回答を優先し、明示的に実作業を依頼されていない限り実装・編集・生成などの作業へ移らない。
- ユーザーからの最新の直接指示がある場合は、その指示を優先する。
