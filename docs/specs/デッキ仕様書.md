# デッキ仕様書

- 最終更新: 2026-09-03
- 文書状態: 実装中
- 位置づけ: 戦闘用の装備と Skill をまとめて保存・切替するデッキ機能の正本。

## 1. 基本方針

- デッキは戦闘用構成だけを扱い、見た目用の髪・目・ひげ・色は含めない。
- 見た目用データは `AvatarAppearance` として別に保存する。戦闘デッキとは独立して維持する。
- `AvatarAppearance.Parts` に保存・合成するパーツは Hair、Eye、Beard、Skin のみとする。旧データに残った戦闘装備パーツは表示用合成時に除外する。
- 旧 `Avatar.Parts` と単一の `SkillLoadout` を正本とする保存形式は廃止する。既存セーブの移行、旧形式の読み込み、互換コードは実装しない。
- デッキを正本とし、現在選択中のデッキをゲーム内の現在装備・戦闘 Skill として適用する。
- デッキ一覧内のアバタープレビューは表示専用とする。対象 `DeckData` と共有する見た目情報を合成して適用し、`CurrentDeckId` や保存データを変更しない。

## 2. 保存データ

- デッキ数は `DeckCount = 3` の定数で固定する。将来の拡張はこの定数の変更で行う。
- デッキIDは `1` から始まり、表示名は固定で `Deck 1`、`Deck 2`、`Deck 3` とする。
- `UserProfileData` は `CurrentDeckId` とデッキ3件を保持する。
- 各デッキは、右手・左手・兜・胴の装備IDをそれぞれ1件ずつ保持する。未装備は `EquipmentId = 0` とする。
- 各デッキは、戦闘用 Skill IDを4枠固定で保持する。空枠は `SkillId = 0` とする。
- 新規セーブでは `Deck 1` を選択中にし、初期所持の戦闘装備を標準構成として保存する。`Deck 2` と `Deck 3` は空デッキとする。

## 3. 整合性と保存

- `DeckManager` が現在デッキの取得、装備・Skillの更新、切替と即時保存を担当する。
- `DeckLoadoutUtility` がデッキの構造正規化と装備スロット判定を担当する。
- デッキの保存時と適用時に同Utilityを必ず呼ぶ。
- 装備を正とし、現在のデッキ装備から候補にならない Skill は空枠へ置き換える。
- 装備の編集、Skillの編集は、現在選択中の `CurrentDeckId` のデッキへ即時反映・即時保存する。
- デッキ切替時は、選択先デッキを整合性チェックして適用し、`CurrentDeckId` を更新して即時保存する。
- `AppearanceManager.SetAppearanceWithDeckEquipment(...)` は戦闘装備を含む表示状態を保存する用途に限定する。見た目変更ダイアログは `SetCosmeticAppearance(...)` のみを使い、デッキを更新しない。
- 現在デッキをアバターへ描画する際は、`PartsManagerAvatarAdapter.ApplyDeckAppearance(...)` を使う。右手・左手・兜・胴の既定パーツを解除してからデッキを適用し、起動直後を含めて同一排他グループの装備が重ならないようにする。

## 4. UIと戦闘導線

- StatusScene にデッキ一覧ダイアログを開くボタンを置く。
- 一覧の各デッキ行は、デッキ名、4装備アイコン、4 Skillアイコン、選択状態を表示する。内容確認のためだけの追加ダイアログは開かない。
- デッキ行を押すと、対象デッキを現在のデッキとして適用する。
- 戦闘中の任意タイミングでは切替を行わない。ただし敗戦後の再挑戦導線では、再挑戦の選択肢と並べてデッキ切替を提示する。
- 敗戦後にデッキを切り替えた場合は、切替後の装備とSkillを適用してから再挑戦する。

## 5. デッキ一覧ダイアログ

- `DialogDeckLoadout` は `Dialog/DeckLoadout` をAddressとして開く。
- Prefab内の `DeckLoadoutItemView` テンプレートを非表示にし、`DeckManager.GetAllDecks()` の件数分だけContent配下へ複製する。
- 各行は現在選択中かを表示し、押下時に `DeckManager.TrySelectDeck(deckId)` で切替・即時保存する。ダイアログは開いたままとし、選択状態を即時更新する。Close時に選択済みであればStatus表示も更新する。
- 各行の `RawImage` は、ダイアログの表示中だけ生成する独立アバター・Camera・RenderTextureでライブ描画する。各アバターのAnimatorは独立して動作する。
- ライブプレビューは、複製元に残る右手・左手・兜・胴の全パーツを解除してから対象デッキの装備を適用する。同じ排他グループの武器やサブアイテムを重ねて表示しない。
- 各行はデッキのSkill 4枠を表示する。攻撃力・防御力の合計値は計算経路を未実装のため、現段階では `--` を表示する。
- 各行の `Parts-SkillItem` にある `Text_Level` はデッキ一覧では使用しないため、常に非表示とする。
