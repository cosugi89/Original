# 世界観仕様書

- 最終更新: 2026-10-11
- 文書状態: 企画方針を確定。シナリオ、演出、アセットは未実装。
- 位置づけ: 物語、結末分岐、非戦闘UIの世界観上の役割を定める。実ゲーム内でプレイヤーに表示するUI、台詞、説明文、通知、報酬名などのテキストは英語に統一する。仕様書・開発用コメント・内部メモは日本語で記述してよい。

## 1. 物語の中核

- 主人公は無言であり、固有の性格、台詞、会話選択肢を持たない。物語上の選択はプレイヤーの戦闘行動だけで示す。
- 正式タイトルは `The Red Fever` とする。劇中でも、赤目の人々を生む現象の通称として同じ名称を用いる。
- 敵の大半は人間で、それぞれが生きる、守る、果たすための理由を持つ。赤い目は外部の影響で防衛本能が過剰化し、目的を邪魔する主人公を敵と認識させる。
- 赤目の原因は `The Red Fever` と呼ばれる。これは病や流行の通称として受け取られており、上位存在の正体を示さない。
- 個別ボスは単なる悪人にせず、生存、責任、執着、誇りなど異なる理由を持たせる。通常撃破では取り返しのつかない結果を倒れ方と以後の不在で示すが、物語中で `kill` や `death` といった直接語は使わない。
- 人間ボスは12体前後を基準とする。最終人数、各人物像、装備、台詞、救済条件はステージ試作後に決める。

## 2. Angel と物語の起伏

- `Angel` は人の心や倫理を持たず、人間が衝突する様子を観察・娯楽として扱う上位存在である。救済、研究、自己防衛などの正当な動機は持たない。
- `Angel` は固有名を名乗らない。チュートリアルでは穏やかな天使のような人外の姿で、パス、危険回避、攻撃、Skill、Goal到達を教える。
- `Angel`は通常、嘘をつかず、危険性や戦闘の必要性だけを選んで示す。殺害以外の解決を意図的に視界から外す、偏向的な案内役とする。
- Home用の `Angel` は、単眼の雲状の人外として正面から表示する。通常形はアイボリー、淡い金、青灰を基調とし、開示後形態は同じ外周シルエットのまま赤・黒へ切り替える。明度を一度下げてから上げる演出だけで、同じ存在の内側が変化したように見せる。
- 開示後の単眼は白目の中央に赤い縦長の瞳孔を1つ置く。Home用の画像は `Assets/Resources/Sprite/Angel/Angel-Front-Normal.png` と `Assets/Resources/Sprite/Angel/Angel-Front-Revealed.png` を基準とする。戦闘用は開示後形態だけを用意し、左向きでコンパクトにデフォルメした `Assets/Resources/Sprite/Angel/Angel-Battle-Left-Revealed.png` を基準とする。
- 起は`Angel`の導入、承は赤目の人々を倒していくボスラッシュ、転は救済により`Angel`の解決が唯一ではないと行動で知ること、結は選択に応じた赤目化または`Angel`との決着とする。
- 救済を一度も経験しないルートでは転が訪れない。正しい討伐の連続に見えるまま爽快さを積み上げ、最後にその爽快さが`Angel`の観察だったとホラーへ反転させる。
- 赤目のボスのうち、`Angel`を認識している者は天使の信者と最後の通常ボス程度に留める。大半は狂気の原因を理解しない。
- 最後の通常ボスは、かつて`Angel`の観察対象であり、人間ボスを全員通常撃破した結果として赤目化した元主人公である。この事実は断片的に示し、明言しない。

## 3. 救済、分岐、結末

- 各人間ボスは通常撃破と救済の二種類の結果を持つ。どちらでも同じボス由来の `Insights` を自動解放し、救済時だけが上位存在戦の安全地帯を1マス追加する。
- 救済条件はUIで明示しない。台詞、所持装備、盤面、戦い方を手掛かりに推理する。準備すれば狙えるが、装備やパスの制約により通常撃破より戦闘自体はやや難しくする。運や一手だけの完全解を要求しない。
- 救済には二種類ある。条件を満たしてGoalを解決した時点で敵HPを残して終える特殊勝利と、条件を満たしたうえで敵HPを0にすると救済へ変換される勝利である。Attack、Skill、装備、回避ノードの累積回数などを条件に使える。
- 序盤の救済は、適切な装備で攻撃する、攻撃連鎖をつなぐなど、戦闘の快感を強める条件を中心にする。攻撃しない救済はプレイヤーの視野が広がる後半に最大2体程度置く。
- 一周目・Resurgenceとも、人間ボスを一人でも救済すれば、最後の通常ボス戦後に`Angel`が赤・黒・禍々しい本来の姿で現れ、上位存在戦へ進む。`Angel`を倒すことが真エンドの条件であり、救済人数は問わない。
- 全員を通常撃破した場合、主人公は赤目化する。赤目化後は、成長・装備・Skill・Abilityを引き継いだ主人公を敵とし、次の観察対象として用意された初期状態の主人公を操作する敗北固定戦へ進む。ここで`Angel`は登場しない。
- 最初の救済後、次の人間ボスを通常撃破した場合、`Angel`はいったん不在にした後に戻り、`I took care of the one you spared.` と嘘をつく。救った人物は実際には生存しており、その理由は明かさない。真エンドのスタッフロールでは、台詞のない一枚絵で生存を示す。
- 上位存在に勝利すると原因が消え、赤目の人々は回復へ向かう。救済した人間ボスのその後をスタッフロールの一枚絵で示す。

## 4. 上位存在戦

- 上位存在戦の勝利条件は敵HPを0にすることとする。専用の特殊勝利条件は設けない。
- 初期盤面ではStart、Goal、Attack / Jump / Rollなどの役割ノード以外を危険マスにする。救済数に応じて、安全地帯候補の危険マスからランダムに安全地帯へ変える。
- 安全地帯は経路選択を緩和するだけであり、`Angel`の攻撃性能、耐久力、勝利条件を下げない。救済数が最大でも最後の通常ボス程度の強さを保つ。
- 役割ノード数、Goal数、安全地帯候補、乱数再現性は、通常ボスの実盤面を試作した後に決める。

## 5. Resurgence と The Remnant

- 一周目のいずれかの結末後、タイトル画面で重要品 `The Remnant` の獲得演出を行う。アイテム画像、名称、`It remains after everything else has faded.`、`Resurgence Unlocked` を表示する。
- `The Remnant` は開始後の `Items` に残る使用不能の重要品であり、タイトル画面でのみ `Resurgence` を解放する。由来や機能理由は明かさない。時間遡行や輪廻転生ではない。
- Resurgenceでは装備、Skill、Traitの進捗、Armoryで解放済みの商品一覧を引き継ぐ。Mission進捗、人間ボスの通常撃破／救済結果、Insights、安全地帯はリセットする。
- ResurgenceではMissionの再クリアによりPointとGoldを再取得できる。第二の成長Treeは設けず、その成長余地はTraitの拡張へ回す。
- Resurgenceのチュートリアルでは`Angel`の台詞を一部変更し、赤字演出を加える。台詞差分は記録一覧へは載せず、直接体験させる。
- Resurgenceで上位存在に敗北した場合は、同じ周回の結果、安全地帯、Insightsを維持したまま再挑戦できる。

## 6. UI、Mission、Armory

- 実ゲーム内の基本UIは英語表記とする。下部Tabは `Character`、`Progress`、`Home`、`Missions`、`Armory` とする。
- `Character` は装備・Deck・Appearance・重要品を扱う。4つ目の入口が必要かどうかは実レイアウトを試作してから決める。`Records`は設けない。
- `Progress` は `Traits` と `Insights` を持つ。`Insights`はボス由来の自動解放能力の一覧で、新規解放時はバッジを表示する。Resurgenceでのみ `Remnant` タブを追加する。
- `Remnant` はボスの通常撃破／救済結果、一周目で聞いたボス台詞、Resurgenceでの救済達成状況を表示する。上位存在へ一度到達した後、通常撃破済みボスの救済目的の再挑戦もここから行う。救済済みボスは再挑戦対象にしない。
- `Missions` は`Angel`が提示する対処依頼の一覧である。移動地図ではない。Main Missionは本筋の人間ボスを順番に提示し、完了後は一覧から消す。Event Missionは任意の1対1戦で、Gold、Armory装備、戦闘パターン、`The Red Fever`の被害を補助的に示す。Eventもクリア後に消す。
- `Armory` はGoldで装備を買うカタログであり、`Angel`が任務のために用意した装備として見せる。進行に応じて品揃えを増やす。救済に必要な装備は、対応ボスへ挑む時点で既に購入可能な商品から選ぶ。
- InsightsはHP、Attack、Defenseの加算に加え、Skill charge促進のような共通の特殊ルールを使える。ボス一体だけに通用する固有ギミックは初期版では作らない。

## 7. 色と演出

- 赤は敵、敵の攻撃性、危険、暴走を示す共通色とする。赤い目、危険マス、敵の攻撃予兆、敵HP、敵Skill由来の状態、被弾、敵Skill演出は赤系を基調とする。
- プレイヤー側と確定済みパスはダークテーマ上で見やすい青緑または淡い青を基調とする。
- `Angel`のチュートリアル形態には赤を使わず、上位存在戦でのみ赤・黒を強く用いる。
