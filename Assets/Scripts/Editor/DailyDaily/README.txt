よく触る GameObject やアセットをブックマークしておき、
クリックまたはショートカットで「インスペクタの表示先」を
一瞬で切り替えられる Unity エディタ拡張です。

シーン内オブジェクトもプロジェクト内アセットも、まとめて
1 か所にブックマークして行き来できます。
ブックマークはプロジェクト単位で保存され、Unity を再起動しても残ります。


------------------------------------------------------------------
■ 必要環境
------------------------------------------------------------------
 - Unity 2022.3

 ※ 特定の SDK や外部パッケージには依存しません。


------------------------------------------------------------------
■ 導入方法
------------------------------------------------------------------
 1. 本パッケージ（.unitypackage）をインポートする
 2. メニュー Tools > DailyDaily > Object Bookmark を開く


------------------------------------------------------------------
■ ブックマークの追加方法（いずれでも可）
------------------------------------------------------------------
 ・ウィンドウの「選択中を追加」ボタン
       … 今 Hierarchy / Project で選択中のものを追加
 ・ウィンドウ内にドラッグ＆ドロップ（枠内に限らずどこでも可）
 ・右クリックメニュー
       Hierarchy : 右クリック > DailyDaily > Add to Object Bookmark
       Project   : 右クリック > DailyDaily > Add to Object Bookmark


------------------------------------------------------------------
■ 表示先の切り替え方
------------------------------------------------------------------
 ・各ブックマークをクリック
       … そのオブジェクトを選択し、インスペクタに表示します。
 ・ショートカット Alt + 1 〜 9 ／ テンキー NUM 1 〜 9
       … 上から N 番目のブックマークに切り替えます。
         テンキーは修飾キーなしの単押しで効きます。
         （割り当ては Edit > Shortcuts… の
           「DailyDaily/Object Bookmark」で変更できます。
           テンキー単押しが他の操作と干渉する場合は、
           ここで修飾キーを足すか割り当てを外せます）
 ・方向キー ↑ / ↓（ウィンドウがアクティブな時）
       … 現在表示中のブックマークの 1 つ上 / 下に切り替えます。

 ※ インスペクタを「ロック」していない通常の状態で機能します。
    複数のインスペクタを開いて一部をロックしておけば、
    ロックしていないインスペクタだけが切り替わります。


------------------------------------------------------------------
■ ウィンドウの操作
------------------------------------------------------------------
 ・各行の左の「⌥1」等 … 対応するショートカット番号の目安
 ・▲ / ▼               … ブックマークの並び替え（番号も連動）
 ・×                    … そのブックマークを削除
 ・「すべてクリア」      … 全ブックマークを削除


------------------------------------------------------------------
■ 注意事項
------------------------------------------------------------------
 - シーン内オブジェクトのブックマークは、そのシーンを開いている間だけ
   解決できます。シーンを閉じている / 対象を削除した場合は
   「(未解決)」と表示されます（× で削除できます）。
 - ブックマークはプロジェクト単位（EditorPrefs）で保存されます。
   別マシンへの同期や、チームでの共有は行いません。
